# nano-banana

AI-powered image generation studio. Users can visualise new outfits on themselves or replace their car with a dream vehicle — all generated by OneShotAPI.

## Stack

- **Frontend**: React 18 + Vite (port 5000 in dev)
- **Backend**: Express (port 3001, proxied by Vite in dev)
- **AI**: OneShotAPI (`ONESHOT_API_KEY` secret)

## Project structure

```
├── server/
│   └── index.js          ← Express API server
├── client/
│   ├── src/
│   │   ├── App.jsx
│   │   └── components/   ← Header, ModeSelector, OutfitGenerator, CarReplacer, …
│   ├── vite.config.js    ← Proxies /api → localhost:3001
│   └── package.json
├── package.json          ← Root workspace: server deps + scripts pnpm
├── pnpm-workspace.yaml   ← Workspace client
├── pnpm-lock.yaml        ← Lockfile pnpm
└── replit.md
```

## How to run

```bash
# Install all workspace dependencies
pnpm install

# Start both servers (dev)
pnpm dev
```

The Vite dev server on port 5000 proxies `/api/*` to the Express server on port 3001.

## Environment variables / secrets

| Key               | Description                    |
|-------------------|--------------------------------|
| `ONESHOT_API_KEY` | OneShotAPI secret key (Replit secret) |

## Adapting the OneShotAPI integration

`server/index.js` contains clear comments on where to update the API endpoint and response-shape mapping once you have confirmed the exact OneShotAPI endpoint paths from their dashboard.
