Use the user-provided complete Astra symbol for browser favicons, Apple touch icons, and web app manifest icons. The canonical supplied artwork is the white symbol on transparency with no surrounding square; it is separate from the visible site logo.

**Why:** On August 7, 2026, the user supplied a white Astra symbol and clarified that the tab and mobile icon must use that complete mark without a square background, while keeping the site logo unchanged. A previous blue-to-violet derivative caused mobile browsers to show the wrong mark.

**How to apply:** Derive all favicon and mobile icon sizes from the same source artwork, keep the visible navigation logo separate, and bump the asset query version when replacing cached icons.
